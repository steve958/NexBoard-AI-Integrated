Testing API endpoints on localhost:3000

Place in: nexboard/public/test-api.html then access via: http://localhost:3000/test-api.html

Configuration

Get this from Settings → Personal API Tokens Get this from the URL when viewing a board: /boards/[projectId]
⚠️ First Time Setup:
Step 1: Copy this file to nexboard/public/test-api.html
Step 2: Make sure dev server is running: npm run dev
Step 3: Open http://localhost:3000/test-api.html in your browser
Step 4: Get your API token from Settings page
Step 5: Get your Project ID from a board URL
